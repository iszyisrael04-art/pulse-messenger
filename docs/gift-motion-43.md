# Gift stories and paragraph chat — 0.1.0+43

Chat and LIVE comments now use a visible Send button. The keyboard paragraph action, Enter and Shift+Enter preserve line breaks; editing a message does not send it. Empty, busy and composing IME states remain guarded.

Rocket: takeoff/exhaust, a banked flight past Earth through stars, moon approach, braking, landing legs, contact dust and a flag. Castle: stone turrets, opening gates, a crowned king walking out and waving. Crown: a brief transparent gift announcement plus a 12-second crown attached to the largest detected face in the host's video tile. It hides when no face is found. Local front-camera mirroring and contained-video letterboxing are mapped before positioning the crown. Android/iOS supply head roll; Windows supplies position with no invented tilt.

The scenes use perspective-projected, shaded triangle meshes with authored phases, not just a rotating gift icon. The existing original lion jungle clip and audio remain bundled. Fifteen original synthesized sound cues add thrust/landing, gates/footsteps/fanfare, crown chimes, fire crackle, butterfly flutters, crystal bells and other gift-specific sounds. All new audio totals about 234 KB, generated by `scripts/generate_gift_sounds.py` with the Python standard library and ffmpeg; no sampled music or paid service is used.

The LIVE menu's gift-sound switch applies to the new cues. Reduced-motion mode uses the silent mesh presentation. Media stops/disposes on leaving the screen, and background/profile navigation pauses audio. Effects ignore pointer input so Exit remains usable; deadlines release a failed effect.

Face positioning is on-device, only while an unexpired crown is visible in a foreground live. Calls are throttled to one at a time, about three per second, using resized disposable snapshots. Android uses bundled ML Kit 16.1.7 (no first-use model download), iOS uses Vision, and Windows uses WinRT FaceDetector on a worker isolate. No face recognition, face template or biometric identity is computed, persisted or sent to Pulse. Disposable WebRTC snapshot files are deleted after processing. The Android detector adds its own packaged model to the APK. No detection loop runs while there is no crown.

Validation: keyboard/multiline button tests, motion phase/landing/gate tests, contained/mirrored face mapping, face-loss/expiry tests, render previews from CI, native runner registration idempotency, and full Actions checks. Device acceptance is still needed for crown placement during fast head movement and the mixed call/gift audio on physical devices.

API references: [LiveKit Flutter](https://github.com/livekit/client-sdk-flutter), [WebRTC snapshot implementation](https://github.com/flutter-webrtc/flutter-webrtc/blob/main/lib/src/native/media_stream_track_impl.dart), [Android face detection](https://developers.google.com/ml-kit/vision/face-detection/android), [Apple face rectangles](https://developer.apple.com/documentation/vision/vndetectfacerectanglesrequest), [Windows face detection](https://learn.microsoft.com/en-us/uwp/api/windows.media.faceanalysis.facedetector.detectfacesasync).
